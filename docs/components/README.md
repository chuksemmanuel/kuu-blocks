# Components & Blocks

Kuu distinguishes between **Components** (reusable, generic UI elements) and **Blocks** (feature-specific implementations that often use components).

## Components

_Low-level building blocks used to construct the interface._

- [Button](/docs/components/button) - Versatile button component with multiple variants and sizes.
- [Drawer](/docs/components/drawer) - Generic slide-out drawer container.
- [Tabs](/docs/components/tabs) - Accessible tab interface.
- [Collection Card](/docs/components/collection-card) - Reusable card for displaying collection details.
- [Product Card](/docs/components/product-card) - Reusable card for displaying product details.
- [Horizontal Scroll](/docs/components/horizontal-scroll) - Draggable horizontal scroll container.
- [Image](/docs/components/image) - Responsive image wrapper.

## Blocks

_High-level features that you can drop into your theme._

- [Cart Drawer](/docs/blocks/cart-drawer) - Slide-out cart with optimistic updates.
- [Search Drawer](/docs/blocks/search-drawer) - Predictive search interface.
- [Quick Add](/docs/blocks/quick-add) - Add to cart functionality from product grids.
- [Avatars](/docs/blocks/avatars) - Stacked avatar display.

## Utilities

_Helper snippets for styling and logic._

- [Typography Style](/docs/utilities/typography) - Fluid typography logic.
- [Spacing & Padding](/docs/utilities/spacing) - Dynamic spacing utility.
- [Flex Style](/docs/utilities/flex) - Flexbox layout helper.
