# Contributing to Kuu Theme

## How to contribute

We ❤️ pull requests. If you'd like to fix a bug, contribute a feature, or just correct a typo, feel free to do so, as long as you follow our [Code of Conduct](./CODE_OF_CONDUCT.md).

If you're thinking of adding a new feature or proposing a new pattern across the theme, please consider opening an issue first. This will allow us to discuss your idea, ensure it aligns with the project's direction, and potentially save you some time.

**Legal:** By submitting a pull request, you agree that your contribution is licensed under the project's [LICENSE](./LICENSE).

## Standards

- **Performance First:** This theme must remain lightweight. Avoid heavy libraries.
- **CRO Focused:** Components should be designed with conversion in mind.
- **Minimalist:** Do not include "bloat" features that belong in apps.
- **Transparency:** Keep logic exposed and extensible (e.g., `window.kuu` objects).

## Steps to contribute

1. Fork the repository: [https://github.com/chuksemmanuel/kuu-theme/fork](https://github.com/chuksemmanuel/kuu-theme/fork)
2. Create your feature branch: `git checkout -b my-new-feature`
3. Commit your changes: `git commit -am 'Add some feature'`
4. Push to your branch: `git push origin my-new-feature`
5. Create a new Pull Request
